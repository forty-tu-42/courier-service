# ИС «Курьерская служба»

Курсовой проект по МДК 05.02 «Разработка кода информационных систем».
Тема: **Разработка информационно-справочной системы «Курьерская служба»** (вариант 26).

Решение включает:

- **WPF-приложение** (C#, .NET 9) — рабочее место администратора, менеджера и курьера;
- **MS SQL Server** — база данных, ограничения, представления, хранимые процедуры и тестовые данные;
- **ASP.NET Core Web API** — REST API с JWT, Swagger и CRUD-операциями;
- **xUnit-тесты** — unit- и интеграционные тесты (10 тестов);
- **Пояснительная записка и презентация** — готовятся отдельно по методичке.

---

## 1. Быстрый старт

### 1.1. Подготовка базы данных

1. Откройте **SQL Server Management Studio**.
2. Подключитесь к серверу `stud-mssql.sttec.yar.ru,38325`
   (SQL Server Authentication: `user93_db` / `user93`).
3. Выберите базу данных `user93_db`.
4. Откройте файл **`KURS_KS_full.sql`** из корня проекта.
5. Нажмите **F5** (Выполнить).

Скрипт можно запускать повторно: он удаляет и создаёт только объекты с префиксом
`KURS_KS_`, не затрагивая работы других студентов.

После выполнения в базе появятся 10 таблиц, 4 представления, 4 хранимые процедуры,
последовательность номеров заказов и тестовые данные (24 заказа).

### 1.2. Запуск WPF-приложения

1. Откройте **`Kursovaya_KS.sln`** в Visual Studio 2022 (17.12+) или Visual Studio 2026.
2. Назначьте стартовым проектом **`Courier.WPF`**.
3. Нажмите **F5**.

Либо из консоли:

```powershell
dotnet run --project src/Courier.WPF
```

### 1.3. Учётные записи

| Логин | Пароль | Роль | Доступ |
|---|---|---|---|
| `admin` | `admin123` | Администратор | всё: заказы, курьеры, клиенты, тарифы, отчёты, пользователи, аудит |
| `manager` | `manager123` | Менеджер | заказы, клиенты, курьеры, тарифы, отчёты |
| `courier` | `courier123` | Курьер | только свои заказы и смена их статуса |

Пароли хранятся в виде SHA-256 от соли и пароля (учебный вариант;
в промышленной системе следует использовать PBKDF2/BCrypt).

## 2. Запуск API

```powershell
dotnet run --project src/Courier.API --urls http://localhost:5080
```

- Swagger UI: <http://localhost:5080/swagger>
- OpenAPI JSON: <http://localhost:5080/swagger/v1/swagger.json>
- Проверка БД: <http://localhost:5080/api/health>

Пример входа:

```http
POST /api/auth/login
Content-Type: application/json

{
  "login": "admin",
  "password": "admin123"
}
```

Далее токен передаётся в заголовке:

```http
Authorization: Bearer <token>
```

Основные группы методов:

| Группа | Маршруты |
|---|---|
| Авторизация | `POST /api/auth/login`, `GET /api/auth/me` |
| Заказы | `GET/POST /api/orders`, `GET/PUT/DELETE /api/orders/{id}` |
| Назначение и статусы | `POST /api/orders/{id}/assign`, `POST /api/orders/{id}/status`, `GET /api/orders/{id}/history` |
| Курьеры | `GET/POST/PUT/DELETE /api/couriers`, `GET /api/couriers/{id}/orders` |
| Клиенты | `GET/POST/PUT/DELETE /api/clients` |
| Тарифы и зоны | `GET/POST/PUT/DELETE /api/tariffs`, `GET /api/zones` |
| Отчёты | `GET /api/reports/deliveries`, `/statuses`, `/courier-load`, `/revenue`, `/monthly` |
| Панель управления | `GET /api/dashboard` |
| Пользователи | `GET/POST/PUT/DELETE /api/users` (только администратор) |


Все 10 тестов проходят.

## 5. Строка подключения

По умолчанию используется учебный сервер:

```
Server=stud-mssql.sttec.yar.ru,38325;
Database=user93_db;
User Id=user93_db;
Password=user93;
TrustServerCertificate=True;
```

Она задана в двух местах:

- `src/Courier.Data/Db.cs` — для WPF и общих сервисов;
- `src/Courier.API/appsettings.json` — для API.

Для другого сервера (например, `localhost\SQLEXPRESS`) измените строку в этих файлах
или задайте переменную окружения `COURIER_DB_CONNECTION`.

## 6. Возможности приложения

### Администратор

- панель управления с KPI;
- заказы: поиск по номеру/клиенту/телефону/получателю, фильтр по статусу и датам;
- создание и редактирование заказа с автоматическим расчётом стоимости;
- назначение курьера;
- смена статуса (Новый → Принят → Назначен → В пути → Доставлен / Отменён);
- клиенты: CRUD, архив;
- курьеры: CRUD, транспорт, зона, статус, архив;
- тарифы: зоны и диапазоны веса;
- отчёты: доставки за период, заказы по статусам, загрузка курьеров,
  выручка по зонам и месяцам; печать и экспорт CSV;
- пользователи и роли;
- журнал аудита.

### Менеджер

Всё, кроме управления пользователями и журнала аудита.

### Курьер

- видит только свои заказы;
- может менять статус своих заказов;
- печать и экспорт своего списка.

## 7. Безопасность

- пароли — SHA-256(соль + пароль), соль уникальна для пользователя;
- роли и права проверяются и в WPF, и в API;
- JWT с подписью HS256 и сроком действия 120 минут;
- параметризованные запросы `Microsoft.Data.SqlClient` — защита от SQL-инъекций;
- ограничения БД: внешние ключи, `UNIQUE`, `CHECK`;
- аудит действий пользователей;
- валидация полей на клиенте и на сервере;
- при ошибках показываются понятные сообщения, а не stack trace.

## 8. Примечания

- Проект собран под **.NET 9** (LTS-ветка, поддерживается Visual Studio 2022 17.12+ и Visual Studio 2026).
  Если преподаватель требует .NET 8, замените `TargetFramework` в `.csproj`
  на `net8.0` / `net8.0-windows` и обновите пакеты — архитектура не меняется.
- Для работы WPF нужен Windows 10/11.
- Для API и WPF используется одна и та же база данных.
- Скрипт БД и приложение проверены на SQL Server 2022.
